# HALCYON-DRAX BIOPRODUCTS

Шуточный интернет-магазин в стиле «Чужого», перенесённый в пустынный киберпанк (ориентиры: «Дюна», «Безумный Макс», культ машинного бога): слизь, яйца, б/у синтетики и прочие товары, которые не стоило везти на Землю. Всё вымышлено, оплаты нет: экипаж — расходный материал.

**Стек:** [Astro](https://astro.build) (статический сайт, товары в Markdown) · Tailwind CSS 4 · [GSAP](https://gsap.com) (анимации, ScrollTrigger, ScrambleText) · корзина в `localStorage` · деплой на GitHub Pages.

## Запуск

```bash
npm install
npm run dev      # http://localhost:4321
npm run build    # статика в dist/
npm run preview
```

## Как добавить товар

Создай файл `src/content/products/<slug>.md`:

```md
---
name: "Слизь ксеноморфа «Кислотная»"
price: 1490            # имперские кредиты
hazardLevel: 5         # 1..5
category: slime        # slime | biotech | gear | food | souvenir | synthetic
glyph: "🧪"            # эмодзи-реликвия, перекрасится в цвет пряности
tagline: "Прожигает три палубы."
inStock: true          # false → «Сбежал со склада»
warnings:
  - "Не открывать над полом"
---

Описание в Markdown: **жирный** — цвет пряности, *курсив* — янтарный.
```

Схема проверяется при сборке (`src/content.config.ts`): опечатку в поле Astro покажет сразу.

## Структура

```
src/
  content.config.ts        схема товаров
  content/products/*.md    каталог (26 позиций)
  layouts/Layout.astro     шапка, сканлайны и песчаное зерно
  components/Relic.astro   реликварий товара: SVG-арка, пустыня, нимб, машинное око
  components/              карточка товара, шкала опасности
  pages/                   каталог, страница товара, трюм (корзина), 404
  scripts/cart.ts          корзина в localStorage
  scripts/relics.ts        GSAP-анимации реликвариев, появления карточек и расшифровки текста
  styles/global.css        тема: пряность, ржавчина, хром и голубой свет Вычислителя
```

## Анимации

Каждый товар выставлен в реликварии (`Relic.astro`, анимирует `scripts/relics.ts`):

- нимб с литанией Синода и шкала-шестерня вращаются навстречу друг другу; чем выше `hazardLevel`, тем быстрее;
- реликвия левитирует, солнце дышит, барханы ползут, через арку несёт песчаную бурю;
- голубой луч Вычислителя сканирует товар, всевидящее око моргает и косится;
- товары с опасностью 4–5 сами сбоят: глитч с расслоением на голубой и красный каналы;
- при наведении нимб раскручивается, геометрия вспыхивает, реликвия сбоит;
- «В трюм» — реликвия по дуге улетает в счётчик корзины;
- карточки «выкапываются из песка» при прокрутке, тексты расшифровываются из рун.

Анимируются только видимые реликварии. При `prefers-reduced-motion` всё остаётся статичным.

## Деплой

`.github/workflows/deploy.yml` собирает сайт и выкладывает его на GitHub Pages при пуше в `main`.
Один раз включи в репозитории: **Settings → Pages → Source: GitHub Actions**.
Сайт будет по адресу `https://<user>.github.io/<repo>/` (base-путь подставляется автоматически).
