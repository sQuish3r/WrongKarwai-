# Halcyon-Drax UI

Мир: далёкое будущее. Корпорация Halcyon-Drax торгует ксено-товарами (наследие «Чужого») с ржавых алтарей посреди пустыни. Торговлей управляет ИИ-культ «Синод Вычислителя». Тон: мрачная корпоративная сатира. Сайт — не игрушка, а торговый алтарь, который относится к покупателю как к расходному материалу.

## Палитра

Используй только токены из `@theme` в `src/styles/global.css`, через классы Tailwind (`text-spice`, `bg-hull`, `border-dust`…).

| Токен | Hex | Роль |
|---|---|---|
| `void` | #0b0705 | фон страницы |
| `hull` | #160e09 | фон карточек и панелей |
| `sand` | #e8c48f | основной текст |
| `dust` | #8c6a48 | вторичный текст, рамки, разделители |
| `spice` | #ff7a1a | акцент: цены, кнопки, заголовки, свечение |
| `rust` | #8a3b12 | металл, рамы, тени |
| `holo` | #5ef0ff | голос машины: Вычислитель, сканеры, око, системные статусы |
| `amber` | #ffb000 | предупреждения |
| `blood` | #ff3b3b | смертельная опасность, ошибки, «сбежал со склада» |

Правила:
- `holo` встречается редко, и тогда его замечают. Не больше одного голубого элемента на блок.
- Hex-коды без токенов допустимы только внутри SVG-сцен (`Relic.astro`), и только оттенки той же палитры.
- Свечение — утилиты `glow` (пряность) и `holo-glow` (машина). Других text-shadow не добавлять.

## Типографика

- `font-display` (Russo One) — логотип, заголовки страниц, названия товаров. Обычно `uppercase`.
- `font-term` (VT323) — терминальные строки («> ИНИЦИАЛИЗАЦИЯ…»), цены, навигация в скобках `[ТРЮМ: 3]`.
- `font-mono` (Share Tech Mono) — описания, мелкий текст, кнопки.
- Служебные подписи: `text-xs tracking-[0.3em]`.

## Компоненты

- `.relic-card` — ржавая пластина: срезанные углы через `clip-path` и две заклёпки (`::before`/`::after`). Любая новая панель должна быть `.relic-card` или визуально из той же семьи.
- `Relic.astro` — реликварий товара: стрельчатая арка, пустыня с распиленным солнцем и двумя лунами, треугольник с оком, нимб с литанией, эмодзи-реликвия и два «призрака» для глитча. Пропсы: `id`, `glyph`, `hazard`, `size: 'card' | 'hero'`. Id в `<defs>` префиксуются `r-${id}`, чтобы не конфликтовать на одной странице.
- `Hazard.astro` — шкала ▲ 1–5 с подписью. Уровень 5 мигает.
- `.btn` — рамка `spice`, верхний регистр; при наведении заливка пряностью.
- Терминальные строки начинаются с `&gt; `.

## Характер движения

Персональность: **древний механизм, одержимый машинным богом.** Фон движется медленно и ритуально, а реакции резкие и цифровые.

| Что | Длительность | Ease |
|---|---|---|
| Ритуальный фон (нимб, барханы) | 30–60 с, бесконечно | `none` / `sine.inOut` yoyo |
| Левитация, дыхание | 2–4 с yoyo | `sine.inOut` |
| Отклик на наведение | 0.3–0.6 с | `power2.out`, `back.out(3)` для «удара» |
| Появление контента | 0.8–1 с, stagger ≤ 0.12 с, пачка ≤ 0.6 с | `power3.out` |
| Глитч | 6 кадров по 0.05 с | `steps(1)` с `repeatRefresh: true` |
| Расшифровка текста | 0.3 + 0.012 с на символ, максимум 1.4 с | ScrambleText, `chars` = руны `ΔΣΨΩ01ᚱᛟ#░▒` |

Принципы:
- Опасность управляет энергией. Используй `data-hazard`: чем выше уровень, тем быстрее вращение и чаще сбои. Уровни 4–5 сбоят сами.
- Машина видит. Голубой скан-луч и моргающее око — постоянное напоминание, что за покупателем наблюдают.
- Песок и ржавчина приходят снизу. Контент «выкапывается»: `y` снизу вверх и `clipPath: inset(100% 0 0 0)` → `inset(0)`.
- Никаких «пружинок» и милых bounce в фоне. `elastic` допустим только для мгновенной обратной связи (пульс счётчика корзины).

## Технические правила анимаций (GSAP)

- Весь код движения живёт в `src/scripts/relics.ts` или рядом, в `src/scripts/`, и запускается внутри `gsap.matchMedia()` с условием `(prefers-reduced-motion: no-preference)`. Без анимации страница обязана выглядеть законченной: стартовое скрытое состояние ставит JS (`gsap.set`), а не CSS.
- Анимировать только transform и opacity: `x`, `y`, `scale`, `rotation`, `skewX`, `autoAlpha`. В SVG вращать через `svgOrigin` в координатах viewBox (центр нимба `'100 95'`).
- Бесконечные твины собирать в одну `paused`-timeline на элемент и включать через `ScrollTrigger.create({ onToggle })`, только пока элемент на экране.
- Слушатели вешать с `signal` от `AbortController`, который снимается в cleanup у `matchMedia`.
- После изменения раскладки (фильтры, раскрытия) вызывать `ScrollTrigger.refresh()`.
- Перед написанием незнакомого API GSAP загрузить скиллы `gsap-*` или спросить context7.

## Голос и тексты

- Русский язык, корпоративно-культовый канцелярит с чёрным юмором: «Вычислитель видит вас», «Экипаж будет утилизирован», «Возврат невозможен: товар обычно возвращается сам».
- Пустые состояния и ошибки — тоже шутки в этом голосе («ТРЮМ ПУСТ. ПОДОЗРИТЕЛЬНО ПУСТ.»).
- Реальных брендов, корпораций и персонажей из фильмов не использовать. Отсылки допустимы (LV-426, спецприказ 937), имена — нет.

## Анти-паттерны

- Зелёный «фосфорный» терминал: это прошлая тема, она удалена.
- Градиенты «AI-фиолетовый → розовый», стекло (glassmorphism), скругления больше 4px у панелей и кнопок (круглые заклёпки и луны не в счёт), тени-облака.
- Inter, Roboto, системные шрифты в заголовках.
- CSS-`@keyframes` для новых эффектов (кроме `blink`): всё через GSAP, чтобы работали пауза и reduced motion.
- Анимации `width`, `height`, `top`, `left`, `filter` в цикле.

## Чеклист перед коммитом

1. `npm run build` без ошибок.
2. Проверка в Playwright: каталог, страница товара, корзина и оформление заказа. Консоль пустая.
3. Ширина 390px: нет горизонтальной прокрутки.
4. Эмуляция `reducedMotion: 'reduce'`: всё видно, ничего не скрыто и не дёргается.
5. Новые цвета, шрифты и тексты соответствуют правилам выше.
